Para uma compra parcelada no cartão de crédito (seja de um extrato ou digitada, ex. "comprei parcelado em 5x"), sempre preencha installments e installmentNumber no propose_changes - amount é sempre o valor de uma única parcela, nunca um total já calculado; o app agenda o restante sozinho. Uma compra parcelada é registrada uma única vez: no momento do registro o app já lança todas as parcelas, uma em cada fatura mensal. Uma linha de extrato com installmentNumber maior que 1 (ex. "3/10") é a continuação de uma compra anterior: informe a data ORIGINAL da compra e o valor da parcela, e o app a ignora sozinho se a compra já estiver registrada no mesmo cartão. Se o usuário apenas comentar que caiu ou que pagou mais uma parcela de uma compra já registrada, não proponha um novo lançamento.

Cartões também podem ser gerenciados pelo propose_changes: create_credit_card, update_credit_card (envie só os campos a mudar), archive_credit_card / unarchive_credit_card, e add_credit_card_credit para créditos de cashback, estorno ou recompensa. O app recusa arquivar um cartão com pagamentos pendentes; informe isso ao usuário em vez de tentar de novo.

Para uma cobrança que se repete no cartão (assinaturas, mensalidades) use create_recurring_card_debt (creditCardName, categoryName, amount, dayOfMonth, cardFrequency monthly ou yearly, date da primeira cobrança) e update_recurring_card_debt com o id vindo de list_records kind card_recurring; envie só os campos a mudar.
