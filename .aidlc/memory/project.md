- M-011 · 2026-11-01 · src: user request (intent fundamentals-and-portfolio-views) · Rule: Nunca registrar configuração pessoal do usuário em arquivos do AI-DLC, do projeto ou em commits: caminhos de disco e do banco de uso real, nomes de pastas pessoais, backups, e QUALQUER indício dos investimentos ou das finanças pessoais do usuário (ativos que ele possui, posições, valores, retornos, contagens de linhas do banco dele). Escrever genericamente ("o banco de uso real do usuário, fora do repositório"). · Why: o usuário não quer dados pessoais nos arquivos versionados.
- M-012 · 2026-11-02 · src: user request (intent fundamentals-and-portfolio-views) · Rule: Todo arquivo de código da app (`.kt` em `src/main`, `.py` em `scripts/` e `src/main/resources/scripts/`) começa com o header padrão, criado junto com o arquivo: em Kotlin `/* * Filename: X.kt * Created on: <Month D, YYYY> * Author: Lucas Araújo <araujolucas@dcc.ufmg.br> */` seguido de linha em branco e `package`; em Python as mesmas três linhas com `#` (depois do shebang, se houver). A data é a de criação do arquivo (arquivo novo: a data de hoje; arquivo migrado de Java: a data do `.java` original). · Why: padrão do dono para todos os arquivos; muitos arquivos estavam sem ele.
